# Resource Clicker

## What is Resource Clicker?
Resource Clicker is a game i made, where you need to click to gain resources, including points and powers. You can reset to boost points and unlock new mechanics. This is also a project i started to learn JS.

## What features does this game have?
So far, it has got 3 prestige layers, several upgrades, rebuyables and milestones. You can unlock most of the main content through unlockers, a rebuyable bought with points.
